Where do coins come from?

A coin is just a number nobody can fake. Two ingredients make that work: a fingerprint function (hashing) and key pairs (wallets).

The fingerprint machine

SHA-256 turns any text into a 64-character fingerprint. Change ONE letter and the whole thing looks different.

Unique coin IDs

id = SHA256( from + to + amount + timestamp )

There are 2256 possible IDs, more than the number of atoms in the Milky Way, so two coins never share one.

Wallets are key pairs

private key → (elliptic-curve math) → public key
address = "" + SHA256(public key)[0..40]

Private key = your signature stamp. Public key = how others check it's really you. You can't go backwards from public to private.

Block #0: the genesis block

Every chain starts with a hard-coded first block. Every later block stores the hash of the one before it, so they're welded together.

blockHash = SHA256( index + prevHash + time + transactions + nonce )

Mining is a guessing game with a real cost

To add a block, find a nonce (a random number) that makes the block's hash start with zeros. There's no shortcut, so you guess millions of times. Win and you get paid.
